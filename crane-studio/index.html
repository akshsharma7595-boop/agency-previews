How These 3D Graphics Are Built

Spline 3D vs Pure Three.js Architecture

1. Where did Debbie's Instagram Reel graphics come from?

Creators like Debbie (@ui.debbie) typically model and animate their tactile 3D assets in Spline 3D (or Blender). Spline is a visual 3D design app built for web UI that exports interactive WebGL scenes with baked lighting, clay shaders, and spring physics.

2. Do you NEED a 3rd party tool?

No. This engine runs in pure Three.js right in the browser! Spline itself exports to Three.js/WebGL behind the scenes. By mounting the presentation screen directly inside the container (rather than a floating side card) and matching Debbie's studio lighting and giant typographic backdrop, Three.js achieves the exact same viral result with 0 dependencies and lightning-fast load times.

3. Can we connect Spline or custom 3D models anyway?

Yes, 100%! If your design team creates a scene in Spline, you can export a .splinecode or .gltf model and load it straight into this website with one line of code.
